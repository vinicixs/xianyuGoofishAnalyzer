PUBLICAR A POLÍTICA NO GITHUB PAGES

1. Crie um repositório público no GitHub, por exemplo:
   xianyu-goofish-analyzer-privacy

2. Envie o arquivo index.html deste pacote para a raiz do repositório.

3. No GitHub, abra:
   Settings > Pages

4. Em "Build and deployment", escolha:
   Source: Deploy from a branch
   Branch: main
   Folder: /(root)

5. Clique em Save.

6. Após o GitHub publicar a página, a URL normalmente seguirá o formato:
   https://SEU-USUARIO.github.io/xianyu-goofish-analyzer-privacy/

7. Abra a URL em uma janela anônima para confirmar que ela é pública.

8. Use essa URL no campo "Privacy policy" da Chrome Web Store.

IMPORTANTE:
- Não altere a política sem revisar se ela continua refletindo o comportamento real da extensão.
- Se futuramente a extensão passar a enviar dados para um servidor próprio ou serviço externo, atualize a política antes de publicar a funcionalidade.
