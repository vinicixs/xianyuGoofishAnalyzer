Xianyu/Goofish Analyzer

Política de Privacidade

Última atualização: 27 de setembro de 2026

1. Visão geral

O Xianyu/Goofish Analyzer é uma extensão de navegador destinada a auxiliar a análise e organização de anúncios nas páginas suportadas do Xianyu/Goofish.

2. Dados processados pela extensão

Para oferecer suas funcionalidades, a extensão pode processar localmente informações visíveis nas páginas do Xianyu/Goofish, como título do anúncio, preço, descrição, dados públicos do vendedor e endereço da página.

A extensão também armazena localmente informações criadas ou escolhidas pelo usuário, incluindo configurações, favoritos, notas, histórico de preços observados, itens selecionados para comparação e caches necessários ao funcionamento das ferramentas.

3. Armazenamento

Esses dados são armazenados no navegador por meio de chrome.storage.local.

A extensão não possui, nesta versão, servidor próprio para sincronização desses dados e não envia favoritos, notas, histórico ou configurações ao desenvolvedor.

4. Acesso aos sites

A extensão executa somente nos domínios configurados do Xianyu/Goofish e utiliza o conteúdo das páginas para fornecer as funções descritas ao usuário.

Ela pode acessar páginas públicas/de vendedor do próprio Xianyu/Goofish para obter informações necessárias às funcionalidades de reputação e análise.

5. Tradução

Quando o usuário escolhe explicitamente abrir a função de tradução, a extensão pode abrir o Google Tradutor com o texto da descrição do anúncio inserido no endereço da página de tradução. Essa ação é iniciada pelo usuário e está sujeita às políticas do Google Tradutor.

6. Compartilhamento e venda de dados

O Xianyu/Goofish Analyzer não vende dados pessoais, não utiliza dados para publicidade personalizada e não transmite os dados armazenados localmente para serviços próprios do desenvolvedor.

7. Backup e restauração

A função de backup permite que o próprio usuário exporte seus dados da extensão para um arquivo JSON. A importação ocorre localmente quando o usuário seleciona esse arquivo.

O usuário é responsável por armazenar e proteger os arquivos de backup que exportar.

8. Exclusão de dados

Os dados locais podem ser removidos ao apagar os dados da extensão no navegador ou ao desinstalar a extensão. Dados antigos que tenham sido migrados do localStorage dos sites durante versões de teste podem continuar no armazenamento do próprio site até que sejam removidos pelo navegador ou pelo usuário.

9. Alterações nesta política

Esta política poderá ser atualizada caso novas funcionalidades alterem a forma como dados são processados, armazenados ou transmitidos.
